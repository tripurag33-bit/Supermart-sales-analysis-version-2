# Supermart-sales-analysis-version-2

Project Overview

This project focuses on analyzing supermarket sales data using Microsoft Excel. The objective is to create an interactive dashboard that helps management understand overall sales performance, product category contributions, outlet performance, geographic-tier performance, and statistical insights.

Key Performance Indicators (KPIs)

- Total Sales
- Average Sales per Record
- Average Item Visibility
- Total Product Records

Analysis & Visualizations

- Product Category Sales Analysis
- Top 4 Product Categories Contribution
- Outlet Type Performance Comparison
- Low Fat vs Regular Product Sales
- Geographic Performance (Tier 1, Tier 2 and Tier 3)
- Sales Distribution and Statistical Analysis
- Product Visibility vs Sales Relationship

Geographic Performance

Analyzed sales performance across Tier 1, Tier 2 and Tier 3 outlet locations using dedicated KPI metrics and charts.

Statistical Analysis

Calculated Mean, Median, Minimum, Maximum, Standard Deviation, Variance and Interquartile Range (IQR) to understand sales distribution and identify unusual records.

Tools Used

- Microsoft Excel
- Excel Formulas
- Charts and Visualizations
- Data Cleaning
- Data Analysis
- Dashboard Design

Project Outcome

Successfully developed a comprehensive Excel dashboard with KPI cards, geographic performance analysis, charts, statistical insights and a project summary to support data-driven business decisions.

Actionable Recommendations


Reallocate High-Visibility Shelf Space (0.16+ Tier): Because the 501 items with 0.16+ visibility average $134.10 per record compared to $145.29 in the 0.08–0.12 tier, cap high-visibility placement and shift display priority toward Household ($149.42 avg) and Dairy ($148.50 avg) products.  
Audit Zero-Visibility Records in Grocery Stores: Investigate the 526 zero-visibility items ($72,649.62 in sales) and Grocery Store outlets (10.49% average visibility vs. 5.86%–6.10% in Supermarkets) to correct display tracking gaps.  
Concentrate Stocking in Tier 2 & Tier 3 Outlets: Tier 3 ($472,133.03) and Tier 2 ($393,150.65) account for 72.0% of total sales with nearly identical average sales per record (~$141), making them primary hubs for Top 4 category inventory (50.6% of total sales).
